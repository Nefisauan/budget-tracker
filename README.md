# Orbit — Kaylie & Nefi

A shared financial observatory. Two profiles, one household ledger, live charts, a 3D split of the month, and counsel that changes with your ages and whatever is coming next (wedding, home, family).

## Profiles

- **Kaylie** and **Nefi** each have their own orbit
- **Together** shows the combined books
- Ages default to 22 — edit them anytime
- A wedding event is already on the timeline; change the date and cost so the advice is honest

## What you can track

Income, needs, fun, savings, and investments — monthly, by person or shared. Everything saves automatically in the browser. Export / import JSON to move the ledger between devices.

## Counsel

Recommendations read:

- how young you are (more years → more equity risk on long-horizon money)
- events inside 24 months (wedding cash stays in cash, not the market)
- savings rate, emergency runway, and whether fun is missing or oversized

## Run locally

```bash
npm install
npm run dev
```

## Deploy

GitHub Pages builds from `main` via `.github/workflows/deploy.yml`. In the repo settings, set Pages to **GitHub Actions**.
